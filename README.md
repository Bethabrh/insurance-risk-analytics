# Insurance Risk Analytics Project (ACIS)

## 📌 Overview
This project analyzes historical car insurance data to identify risk patterns, improve pricing strategies, and support data-driven marketing decisions for AlphaCare Insurance Solutions (ACIS).

The analysis includes:
- Exploratory Data Analysis (EDA)
- Risk feature engineering (Loss Ratio, Margin)
- Geographic and demographic segmentation
- Time-series analysis of claims
- Data version control using DVC
- Predictive modeling (future phases)

---

## 📊 Dataset
The dataset contains insurance policy, client, vehicle, and claim information covering Feb 2014 – Aug 2015.

Key variables:
- TotalPremium
- TotalClaims
- Province
- VehicleType
- Gender
- TransactionMonth
